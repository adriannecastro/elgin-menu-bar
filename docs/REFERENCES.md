# References

Documentation and project resources for Elgin devices, Tuya integrations, and local device control.

- [Elgin Wi-Fi manual](https://d2u2qhufg0q9tn.cloudfront.net/assets/arquivos/manual_1d4b2ffe-30ba-4462-ae9d-c8cb5eeddb69_Manual_WIFI__0046_REV06.pdf): app and device information; it does not establish protocol compatibility for every model.
- [Elgin smart bulbs](https://blog.elgin.com.br/iluminacao/lampadas-inteligentes/): product information for Elgin smart lighting.
- [TinyTuya](https://github.com/jasonacox/tinytuya): device discovery, LAN protocols, and cloud-based key retrieval.
- [Tuya: Link Devices](https://developer.tuya.com/en/docs/iot/link-devices?id=Ka471nu1sfmkl): device linking methods and requirements.
- [Tuya: OEM app data centers](https://developer.tuya.com/en/docs/iot/oem-app-data-center-distributed?id=Kafi0ku9l07qb): data center regions for OEM apps.
- [Tuya: Device Data Sharing](https://developer.tuya.com/en/docs/iot/device_data_sharing_usage?id=Kex4vski8ylak): regional and business requirements.
- [Tuya: Query Things Data Model](https://developer.tuya.com/en/docs/cloud/bd68171262?id=Kcp4utbhzzfgo): full device model and field access permissions.
- [Elgin Smart on Google Play](https://play.google.com/store/apps/details?id=com.elgin.smart): official Android app listing.
